# `/docs` Directory

## 1. Purpose
This directory stores academic, architectural, and presentation documentation for the project, including design specifications, milestone review reports, viva preparation materials, and slide deck outlines.

## 2. Contents
- `addressing_plan.md`: Comprehensive network addressing specification, interface maps, and subnet allocation tables.
- `design_notes.md`: Architectural decisions, routing protocol Administrative Distance tuning, SVI topologies, and Packet Tracer behavioral caveats.
- `simulation_guide.md`: Step-by-step Packet Tracer Simulation Mode lab manual covering PDU dissection for DNS, TCP handshakes, UDP streaming, and OSPF failovers.
- `server_setup.md`: Configuration manual for the central Server-PT hosting internal DNS, HTTP clinical portal, and DHCP relay pools.
- `vlsm_report.txt`: Plain-text output of the VLSM subnet allocation engine.

## 3. Subdirectories & Planned Deliverables
- `/docs/reviews/`: Review 1, Review 2, and Final Review project reports (`review_1_report.pdf`, `final_report.docx`).
- `/docs/viva/`: Viva questions, examiner defense notes, and protocol theory cheat sheets.
- `/docs/slides/`: PowerPoint or Markdown presentations (`review_1_slides.pptx`, `final_presentation.pptx`).

## 4. File Naming Rules
- Technical specification documents must use lowercase with underscores: `<topic>_<descriptor>.md`.
- Formal academic reports must follow `review_<n>_report.<ext>` or `final_project_report.<ext>`.
- Presentation slide decks must follow `review_<n>_slides.<ext>`.
